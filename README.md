# VIBE AGY Qualification Lab

Reusable, synthetic-only qualification project for VIBE CODE runtime
provisioning, Antigravity adapters, Universal Safe Runner, runtime overlays and
future compatible runtimes.

This repository has no production or business function. It contains no MISA or
CPGS data, personal/confidential data, credentials, or secrets.

## Static qualification fixture

Open `prototype/index.html` directly, or serve it with:

```powershell
python -m http.server 8000 --directory prototype
```

The fixture is dependency-free: no package installation, framework, remote
asset, CDN, or JavaScript dependency is required.
